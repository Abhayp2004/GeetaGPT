# GeetaGPT

GeetaGPT is a Bhagavad Gita question-answering/chatbot project repository.

At the moment, this repository mainly contains the source dataset and initial project structure.

## Repository Contents

- `geeta_dataset.csv` — Bhagavad Gita verses with multilingual fields:
  - chapter
  - verse
  - sanskrit
  - hindi
  - english
- `app.py` — placeholder for the Python application entrypoint
- `geetagpt_core.py` — placeholder for core backend/chat logic
- `requirements.txt` — placeholder for Python dependencies
- `ui/src/app.jsx` — placeholder for frontend UI implementation

## Dataset

The dataset file `geeta_dataset.csv` includes verse-level content from the Bhagavad Gita in Sanskrit, Hindi, and English.  
This can be used for retrieval, prompting, and multilingual response generation.
